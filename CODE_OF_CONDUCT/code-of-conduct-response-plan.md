# Code of Conduct response plan

This document defines the process maintainers should follow when responding to a report under the K7PL Code of Conduct.

**Document version:** 1.0.0  
**Last updated:** 2026-10-06  
**Audience:** community moderators and maintainers.

## Principles

Respond promptly, respectfully, consistently, and proportionately. Protect reporters and participants from retaliation. Preserve confidentiality and document only information necessary for investigation and response.

## Intake

1. Acknowledge the report.
2. Record an incident identifier.
3. Record the date and moderator responsible for intake.
4. Determine whether immediate safety or access measures are required.
5. Ask whether the reporter permits investigation where relevant.
6. Store the incident record outside the public repository.

## Triage

Classify the report according to the available evidence: no apparent violation; possible violation; confirmed violation; urgent safety concern; or specialist/legal referral.

Do not publish identifying information in issues, pull requests, commits, or public documentation.

## Investigation

Collect only relevant evidence. Give affected parties a reasonable opportunity to provide information. Separate observed facts from interpretations and record unresolved uncertainty.

Where possible, use more than one moderator for consequential decisions. If independent moderation is unavailable, record that limitation.

## Decision

Determine whether the Code of Conduct was violated and select a proportionate response consistent with the adopted policy. Record findings, evidence, decision, rationale, actions, deadlines, and any review route.

## Communication

Communicate outcomes on a need-to-know basis and avoid unnecessary disclosure of personal information.

## Follow-up

Record completion, monitoring needs, and any required improvement to project policy, documentation, moderation, or contributor experience.

## Records

Use [code-of-conduct-incident-record.md](code-of-conduct-incident-record.md) and [code-of-conduct-remediation-record.md](code-of-conduct-remediation-record.md).

Do not commit completed records containing personal data to this repository.
