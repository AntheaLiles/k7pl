# Code of Conduct documentation set

This directory contains operational templates associated with the adopted [Code of Conduct](../CODE_OF_CONDUCT.md).

**Document version:** 1.0.0  
**Last updated:** 2026-10-06  
**Audience:** community moderators and maintainers.

The root CODE_OF_CONDUCT.md remains the public project policy. This directory contains:

- [code-of-conduct.md](code-of-conduct.md): revision template;
- [code-of-conduct-response-plan.md](code-of-conduct-response-plan.md): moderator response procedure;
- [code-of-conduct-incident-record.md](code-of-conduct-incident-record.md): private incident record template;
- [code-of-conduct-remediation-record.md](code-of-conduct-remediation-record.md): private remediation record template.

Completed incident and remediation records must never be committed to the public repository.

The structure follows [The Good Docs Project templates](https://gitlab.com/tgdp/templates/) while being adapted to K7PL.
