## Context and Problem Statement

What forces the decision, in two or three paragraphs. Facts carry their source (file and line,
run, issue, external page); interpretations are marked as such.

## Considered Options

- Option 1 — one line.
- Option 2 — one line.

## Decision Outcome

Chosen option: "Option N", because … (only the owner's stated reasons; if none were given,
say so).

For a Proposed ADR: the proposed decision, written so that the owner can accept or reject it as
it stands.

### Consequences

- Good, because …
- Bad, because …

### Confirmation

The check that enforces the decision: a CI job, a test, a Lean artefact, or "none yet".

## Owner decisions already given

Only for a Proposed ADR that the owner has partly decided: quote the owner's words, cite the
register row, and state which clause they settle and which they leave open.

## Open questions

Questions that block acceptance, with their identifier.

## More Information

Sources, related ADRs, superseded text, notes on how the record was produced.
