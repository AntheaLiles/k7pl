# Ratification D8

Option A ratifiée : conserver une convention globale de soustraction tronquée prolongée, avec ω ⊖ ω = ω, dans les couches où Consume est utilisée. Les différences de couche déterminent les opérations requises localement mais ne définissent pas à elles seules des variantes de ⊖. Les six démonstrations concernées doivent être auditées. Aucune preuve Lean ni modification de spec/ ou src/ n’est revendiquée. La porte C demeure NON SATISFAITE.
