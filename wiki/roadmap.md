## How to read this page

One section is one action lot, written for an agent that reads
only that section. A section is action-ready when it contains,
in this order: **Objective** (one sentence), **Context and
decisions** (what is already decided or open, with precise
pointers to [decisions](decisions.md) and to
[assurance](assurance.md) or [research](research.md)),
**Inputs** (files and sections the agent must read, and only
those), **Tasks** (what to do, in order), **Typology** (the
single primary typology of the section, from the table below),
**Acceptance criteria** (verifiable, not "work done"),
**Dependencies and order** (what must come first, what is
blocked), **Out of scope** (what the section must not do or
decide), and **Proof of completion** (the evidence that
allows ticking the box). If a section does not name an input,
the agent must not invent one; if it does not name a decision,
the agent must not take one. Titles are descriptive, in plain
language. Former codes, where they are indispensable to find a
source section, appear only as a secondary provenance note,
never as a title.

## Typologies

An action is classified by what would count as finishing it,
not by the artefact it touches. The same artefact can be
defined but not proved, built but not checked, or checked but
not decided. That distinction is the point of the typology.

| Typology | What it means | Evidence of completion |
| --- | --- | --- |
| Decide | A choice only the owner can make. | Decision recorded in [decisions](decisions.md), with date and rejected options. |
| Define | Make a concept unambiguous. | Definition in the wiki, with an example and, where relevant, a counterexample. |
| Prove | Establish a formal obligation. | Lean theorem with an axiom audit, no sorry, or an explicit hypothesis with a reduced claim. |
| Build | Construct an executable or a tool. | Code or generator in the repository, with a test run. |
| Check | Verify independently. | Test, CI run, reproduction, or audit report at a named commit, not an author claim alone. |
| Document | Consolidate and trace. | Validated wiki page, old source deleted, links updated. |
| Publish | Make public or archive. | Release, regenerated wiki, or archived record with an identifier. |
