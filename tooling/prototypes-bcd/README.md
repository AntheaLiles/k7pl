# K7PL — Prototypes d'outillage B/C/D

Ce répertoire contient, sur la branche dédiée `tooling/prototypes-bcd`, le matériau extrait des anciennes annexes normatives B, C et D.

Ces documents sont des prototypes d'outillage et ne constituent pas la spécification normative ni la future bibliothèque standard.

La provenance des fichiers est conservée dans leur en-tête. Leur contenu pourra être réorganisé lorsque l'architecture d'outillage sera définie.

Cette branche est volontairement séparée de `main`.
