# Revue

Séparer au minimum :

1. correction technique ;
2. adéquation au contrat ;
3. cohérence spec ↔ code ;
4. qualité et maintenance ;
5. sécurité quand applicable.

Une revue ne doit pas se contenter de relire le diff : vérifier les fichiers et contrôles nécessaires.

Les critiques doivent être actionnables et classées par sévérité.
