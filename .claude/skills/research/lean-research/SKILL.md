# Recherche Lean

Vérifier d'abord les sources versionnées du dépôt.

Puis consulter la documentation et les sources officielles correspondant aux versions utilisées.

Pour une API :

`chercher → lire la signature → vérifier avec Lean → tester`.

Ne pas substituer une API d'une autre version sans le signaler.

Une réponse de recherche doit préciser la version considérée lorsqu'elle affecte la validité de l'information.
