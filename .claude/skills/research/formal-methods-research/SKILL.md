# Recherche méthodes formelles

Privilégier les sources primaires :

- article original ;
- spécification ;
- RFC ;
- documentation officielle ;
- code source ;
- thèse lorsque nécessaire.

Séparer ce que la source dit de l'interprétation pour k7pl.

Chaque conclusion importante doit être associée à une source précise.

Ne jamais transformer « courant dans la littérature » en « vrai pour k7pl » sans argument.
