# Édition de la spécification

Lire `.claude/rules/specification.md` et `.claude/rules/documentation.md`.

N'éditer que sur demande explicite.

Processus :

1. localiser précisément la cible ;
2. identifier les dépendances ;
3. définir la modification minimale ;
4. modifier uniquement les fichiers nécessaires ;
5. compiler ;
6. rendre la spécification ;
7. exécuter les contrôles Verso ;
8. mettre à jour le suivi si requis.

Ne pas corriger simultanément l'implémentation pour « faire correspondre » le texte, sauf demande couvrant explicitement les deux.

Ne jamais changer le statut ou l'énoncé d'un théorème principal silencieusement.
